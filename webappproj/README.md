# Spring Boot REST API Learning Project

## About the Project

This project was built while learning Spring Boot and REST APIs.
The main goal of the project was to understand how backend applications work and how APIs handle requests and responses.

Through this project, I practiced creating REST endpoints, organizing code using layered architecture, and working with Spring Boot annotations.

---

## What I Learned

* Building REST APIs using Spring Boot
* Handling GET and POST requests
* Using Controller and Service layers
* Dependency Injection with `@Autowired`
* Working with `@RestController`
* Using `@PathVariable` and `@RequestBody`
* Basic backend application flow
* API testing using Postman

---

## Features

* View all products
* View product by ID
* Add new products
* In-memory product storage for learning purposes

---

## Technologies Used

* Java
* Spring Boot
* Maven
* REST API
* Postman

## Purpose

This is a practice project created as part of learning backend development and Spring Boot fundamentals.
It helped me understand how APIs are created, how data flows between layers, and how client requests are processed in a Spring Boot application.
